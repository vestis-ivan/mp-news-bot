# MP News Bot

Парсер ТГ-каналов про маркетплейсы (Ozon/WB) и маркетинг **с админкой в Telegram**.
Слушает ~60 каналов через Telethon, фильтрует рекламу, делает AI-саммари, шлёт в твои чаты/темы.

## Что нового

- 💬 **Админ-панель прямо в боте**: добавляй/удаляй каналы, ставь на паузу, смотри статистику — кнопками или командами.
- 🎯 **`/here`** — назначай куда слать новости из ТОГО чата, где написал команду. Работает с темами в супергруппах.
- 🧾 **Недельный AI-дайджест**: бот копит посты всю неделю и по понедельникам после 09:00 МСК отправляет только самые главные новости.
- 🗞️ **Отдельная VC.ru/Ozon-сводка**: по понедельникам после основной ТГ-сводки бот собирает важное с vc.ru, отдаёт приоритет Ozon и шлёт отдельным сообщением в MP-чат.
- 🛡️ **Админка по подтверждению**: `/admin` и `/admin11i` отправляют заявку владельцу, доступ не выдаётся всем подряд.
- 🔎 **Диагностика**: `/health`, `/queue`, `/sources`, `/checkchannels`, `/autopause`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие |
| `/admin` | запросить доступ к админке |
| `/admin11i` | скрытая команда запроса доступа |
| `/menu` | главное инлайн-меню |
| `/here mp_news` | назначить ЭТОТ чат/тему как приёмник MP-новостей |
| `/here marketing` | то же для маркетинга |
| `/hereremove mp_news\|marketing\|all` | снять назначенный приёмник |
| `/add @username mp_news\|marketing` | добавить канал |
| `/addlist mp_news` | добавить несколько каналов списком |
| `/remove @username` | удалить |
| `/move @username mp_news\|marketing` | переключить категорию |
| `/pause @username` | поставить канал на паузу |
| `/resume @username` | снять с паузы |
| `/list [mp_news\|marketing]` | список каналов, с инлайн-меню |
| `/stats` | статистика за сегодня и вчера |
| `/runjob` | preview дайджеста админам, очередь не очищается |
| `/runjob marketing` | preview только маркетинга |
| `/runjob yesterday marketing` | preview категории за дату/день |
| `/runjob send` | отправить дайджест в целевой чат, очередь не очищается |
| `/runjob send marketing` | отправить только маркетинг |
| `/runjob send marketing 2026-05-25` | отправить категорию за дату |
| `/runvc` | preview отдельной VC.ru-сводки по Ozon/WB |
| `/runvc send` | отправить VC.ru-сводку в MP-чат |
| `/queue today all` | посмотреть накопленные посты |
| `/queue today all quarantine` | посмотреть отсеянное |
| `/clearqueue today all` | вручную очистить очередь |
| `/sources 7` | качество источников за N дней |
| `/autopause 7 0.8 5` | кандидаты на паузу: дни, доля мусора, минимум постов |

| `/checkchannels` | проверить доступ к каналам |
| `/catchup 36` | окно догоняющего сканера в часах |

## Архитектура

```
[60 ТГ-каналов]
     ↓ MTProto (Telethon, user session)
[bot.py — слушатель]
     ↓ фильтр рекламы → AI-саммари → роутинг по категории
[Бот @твой_бот] ─→ MP-новости (чат+тема)
              └──→ Маркетинг (чат+тема)
[admin_bot.py — управление через того же @твой_бот]
     ↓ кнопки + команды
[SQLite data/state.db]  ← источник правды
```

Один Telegram-бот выполняет ДВЕ роли:
1. **Отправляет** новости в целевые чаты/темы (он должен быть админом в них).
2. **Отвечает** на команды админов в личке.

## Установка на VPS (Ubuntu)

### 1. Получить Telegram API-ключи (для user-сессии)

https://my.telegram.org → API development tools → создай app → запиши `api_id`, `api_hash`.

### 2. Создать бота у @BotFather

В Telegram: `@BotFather → /newbot → выбери имя → скопируй TOKEN`.

### 3. Куда слать новости — варианты

**Вариант A (просто):** два отдельных канала
- Создай канал «MP-новости» → настройки → Администраторы → добавь своего бота с правом «Публикация сообщений»
- То же для канала «Маркетинг»
- Открой каждый канал → напиши боту в личку `/here mp_news` пока ты В этом канале как админ... **нет, проще** — см. вариант B

**Вариант B (удобнее):** одна супергруппа с темами
- Создай супергруппу → настройки → включи «Темы»
- Создай темы: «MP-новости» и «Маркетинг»
- Добавь бота админом группы (право «Публикация сообщений» и «Управление темами» необязательно)
- Зайди в тему «MP-новости» → напиши `/here mp_news`
- Зайди в тему «Маркетинг» → напиши `/here marketing`
- Готово. Новости летят в правильные темы.

### 4. OpenAI ключ

https://platform.openai.com/api-keys → создай ключ → пополни баланс на $5 (хватит на полгода).

### 5. Клонировать на VPS и заполнить .env

```bash
git clone <твой репо> mp-news-bot   # или scp архив
cd mp-news-bot
nano .env
# Заполни TG_API_ID, TG_API_HASH, TG_PHONE, TG_BOT_TOKEN, OPENAI_API_KEY
```

### 6. Первый запуск (интерактивный — введёшь код из ТГ)

```bash
docker compose build
docker compose run --rm bot
```

Появится:
```
Please enter the code you received: 12345
Please enter your password (if any): ********
```

Telethon сохранит сессию в `data/user.session`, больше пароль не понадобится. Прерви `Ctrl+C`.

### 7. В фоне 24/7

```bash
docker compose up -d
docker compose logs -f --tail=100
```

### 8. Открой своего бота в Telegram и нажми `/admin`

После подтверждения владельцем ты в админах. Теперь:
- В нужном чате/теме напиши `/here mp_news` и `/here marketing` — задай приёмники.
- Используй `/menu` для управления каналами.

## Логика дайджеста

- Новые посты попадают в очередь `daily:<дата>:<категория>`.
- Очевидная реклама режется regex-фильтром, скрытая реклама и шум отсеиваются OpenAI в карантин.
- По понедельникам после 09:00 МСК бот отправляет AI-сводку за прошлые 7 дней и только тогда очищает недельные очереди.
- В дайджест попадают не все посты, а только самые важные новости недели: правила, тарифы, сроки, деньги, реклама, карточки, логистика, штрафы и практичные гипотезы.
- Ссылки в отчетах прячутся в красивые кликабельные заголовки, без голых URL в тексте.
- Если дайджест длинный, бот отправляет все части в назначенный чат/тему, а не только первое сообщение.
- Если новый `/here marketing` ставится туда, где раньше был `/here mp_news`, старый MP-приёмник автоматически снимается, чтобы категории не смешивались.
- После основной сводки отдельный воркер в 09:20 МСК собирает недельные материалы с vc.ru, отдаёт приоритет Ozon и добавляет немного WB только при реальной важности.
- Если OpenAI упал, очередь сохраняется, шумный архив вместо дайджеста не отправляется.
- `/runjob` делает preview админам и не чистит очередь; `/runjob send` отправляет в целевой чат, но тоже не чистит очередь.
- Догоняющий сканер каждые 5 минут проверяет последние посты всех каналов из БД, поэтому добавленные через админку каналы работают без рестарта.

## Управление

```bash
docker compose restart      # перезапустить (после правки config.yaml)
docker compose logs -f      # смотреть логи
docker compose down         # остановить
git pull && docker compose build --no-cache && docker compose up -d  # обновить
```

## Troubleshooting

**`Канал @xxx недоступен`** — твой аккаунт из `TG_PHONE` не подписан на канал. Подпишись и `docker compose restart`.

**Бот не отвечает на команды** — проверь что `TG_BOT_TOKEN` правильный и бот не выключен (`/start` у @BotFather).

**Новости не приходят в канал/тему** — проверь:
1. Бот добавлен админом в этот чат с правом публикации
2. Ты сделал `/here mp_news` (или `/here marketing`) ВНУТРИ этого чата/темы
3. В `/menu → Куда слать` бот покажет назначенные таргеты

**Хочу выключить AI-саммари** — `config.yaml` → `ai.enabled: false` → `docker compose restart`.

## Безопасность

Команды `/admin` и `/admin11i` не выдают доступ автоматически. Бот отправляет заявку владельцу из `ADMIN_APPROVER_USERNAME`/`ADMIN_APPROVER_USER_ID`; владелец подтверждает или отклоняет кнопками.
